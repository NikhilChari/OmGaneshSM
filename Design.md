# Om Ganesh Sanskrutik Mandal
## Design System

---

# 1. Design Direction

The website should combine:

Traditional Indian cultural aesthetics

with

Modern premium web design.

The design should feel:

- Cultural
- Welcoming
- Trustworthy
- Elegant
- Community-oriented
- Modern
- Warm

Avoid making the website look overly corporate.

Avoid excessive decorative elements.

---

# 2. Color Direction

Primary:

Deep Saffron

Secondary:

Warm Gold

Background:

Warm Ivory / Off-white

Text:

Deep Charcoal

Accent:

Deep Maroon

Success:

Traditional Green

The exact color values should be finalized during the design phase.

---

# 3. Typography

Primary font:

Inter or another clean modern sans-serif.

Cultural headings may use a complementary serif or Devanagari-compatible font where appropriate.

Typography should prioritize readability.

---

# 4. Layout

Use generous spacing.

Use:

- Large hero sections
- Rounded cards
- Clear section hierarchy
- Consistent containers
- Responsive grids

Maximum content width:

Approximately 1200–1280px.

---

# 5. Navbar

Desktop:

Logo
Home
About
Events
Gallery
Membership
Contact

Primary CTA:

Join Us

Mobile:

Hamburger menu.

Navbar should remain visually consistent throughout the website.

---

# 6. Hero

The hero should prominently showcase:

- Mandal name
- Short tagline
- Cultural imagery
- Primary CTA
- Secondary CTA

Hero imagery should represent the actual Mandal whenever possible.

---

# 7. Event Cards

Event cards should contain:

- Event image
- Date
- Category
- Title
- Short description
- Location
- Time
- CTA

Cards should have subtle hover animations.

---

# 8. Gallery

Use a visually rich grid.

Support:

- Images
- Videos
- Filtering
- Lightbox

Avoid overly uniform layouts when the photography benefits from masonry-style presentation.

---

# 9. Buttons

Primary button:

Saffron/gold themed.

Secondary button:

Outlined.

Buttons should:

- Have clear hover states.
- Have accessible contrast.
- Have sufficient touch area.

---

# 10. Animation

Animations should be subtle.

Use:

- Fade
- Slide
- Scale
- Hover transitions

Avoid excessive animations.

Respect reduced-motion preferences.

---

# 11. Responsive Design

Design for:

Mobile first

Then:

Tablet

Then:

Desktop

Important breakpoints should be determined by layout requirements rather than arbitrary device sizes.

---

# 12. Accessibility

Ensure:

- Good color contrast.
- Keyboard navigation.
- Visible focus states.
- Alt text.
- Semantic HTML.
- Accessible forms.
- Screen-reader-friendly labels.

---

# 13. Imagery

Prefer authentic photographs from:

- Mandal events
- Cultural programs
- Community activities
- Festivals
- Members

Avoid generic stock photography whenever actual Mandal photography is available.

---

# 14. Overall Feel

The final website should feel like:

"A modern digital home for a traditional community organization."

It should not feel like:

- A generic template.
- A corporate website.
- An AI-generated landing page.
